# Zorya's Advanced Medical

## Features
- Poppy plant, opium-derived painkillers (morphine, heroin) and synthetic fentanyl
- One shared opioid addiction and tolerance across all three drugs
- (Planned/WIP) Blood bags, saline, automatic usage of said bloodbag and saline, heart rate monitoring and blood pressure, many other things

## Requirements
- RimWorld 1.6
- Will probably use harmony once i figure out what exactly what its used for xd
- I plan to keep this mod available to everyone and do not want it locked behind any of the DLC content. 

## Installation
- **Manual:** download the ZIP or clone into `RimWorld/Mods/`
- **Steam:** I plan to publish it once there are a lot more features and its actually worth using.

## Compatibility
For now should work with all mods as it just adds some items.
